# 🎓 CampusPortal - College Search, Predictor & Discussion Forum

A full-stack Spring Boot web application for exploring colleges, predicting admission eligibility by exam ranks, and campus discussions.

## 🛠️ Features
- **College Search & Multi-filter:** Search by city, fees, rating, and placements.
- **AI Rank Predictor:** Predict colleges based on entrance exam ranks (JEE/NEET).
- **Discussion Forum:** General community forum and college-specific discussions.
- **Authentication:** Login and registration system.

## 💻 Tech Stack
- Java, Spring Boot, Spring Data JPA, Thymeleaf, Tailwind CSS
